# v0.5 — Presentation & Routing Edition

- Three primary tabs only: Rock Vision, Legacy Document AI, Model Pipeline.
- Project/privacy/model details moved into a collapsed header accordion.
- Light/Dark buttons use Gradio event JavaScript rather than script tags embedded in HTML.
- Legacy Document AI now shows a page-1 preview immediately after upload.
- Added local `eng+rus` Tesseract language-pack support and a Windows installer helper.
- Model Pipeline visualizes TEXT → OCR and FIGURE → Rock Vision on the first routing map.
- Added an explicit per-run method/model table.
- Rock overlays now use class-specific colors and prefixes: G/P/V/F/C.
- Large pore objects are displayed separately as vugs.
- Object labels are limited to large objects for cleaner screenshots.
